Our recommendation is to adopt a small, disciplined system rather than many logos. The core mark everywhere, the bold-seam version only at small sizes, the horizontal lockup when the name is needed, and the stitched version for merchandise. The other versions stay in the toolkit for specific jobs, as described in the families.
