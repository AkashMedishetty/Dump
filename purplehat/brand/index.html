The PhE logo, as files, as code and in motion.

Round-capped strokes of one width and three dots on the baseline. People + places = experiences: a pill and a circle are the pattern language, and the dots are the animation device.

Look at these first
  1. contact-sheet.png — the whole SVG set on one page
  2. animation/player.html — the four animations, live, with sound
  3. code/README.md — the logo as a JS module, React component and CSS

Mark

The primary mark is a single colour. Two-tone (dots in accent) is for motion, social and anywhere the dots lead. Reversed files carry the minimum clear space as padding.

Lockups

The wordmark is set in DM Sans 500 as a stand-in for Satoshi Medium (Fontshare could not be reached from the build machine). Swapping it is one setting: see README.md.

App icon and favicon

The full mark needs 120 px of width, so the favicon uses the P and its dot. App icons are full-bleed squares (the OS applies its own mask); the mark sits inside the maskable safe zone.

Clear space and minimum size

Motion: the dots are the hero

Every animation is a deterministic page (window.render(t)), rendered frame by frame to MP4 at 1920×1080, 1080×1920 and 1080×1080, 30 fps, on neutral and on primary, with sound at −16 LUFS. The landings fall on a 150 bpm grid.

Open the player for sound, scrubbing and the vertical and square formats. Transparent versions of A for editors: animation/alpha/ (ProRes 4444 .mov and VP9 .webm with alpha).

In code

Same geometry, same choreography: the CSS keyframes are sampled from the JS presets that drive the videos. Click a tile to replay.

import { svgString, mount } from './code/phe-logo.js';

// static markup (SSR, emails, OG images)
el.innerHTML = svgString({ layout: 'primary', variant: 'reversed' });

// live: strokes draw on, dots drop on the beat
const logo = mount(el, { variant: 'twotone' });
logo.play('draw-drop').finished.then(() => logo.play('breathe'));
import { PheLogo } from './code/PheLogo';

<PheLogo variant="twotone" animate="draw-drop" size={96} />
<PheLogo layout="horizontal" size={40} />
<PheLogo animate="breathe" color="#000" dotColor="#2563EB" />
