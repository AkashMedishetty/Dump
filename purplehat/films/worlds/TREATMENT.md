# WORLDS — every style in the library, one PurpleHat mark

75 s · 16:9 + 9:16 · 24 fps · 120 bpm · −14 LUFS · no voice

## Idea
An events company is asked to build a different world every week. The film walks through 43 of them —
a 1930s gala, a hackathon, a Japan incentive, a haunted-house build — each drawn in a different medium
(the 43 Lemo-Opuscar styles). Nothing else stays the same except the PurpleHat mark: same place, same size,
redrawn in every material (gold leaf, glyph density, cut paper, toy bricks, neon, knife-laid paint, glass).
Ending: "PurpleHat Events — 43 worlds. One call."

## Seamless grammar (the carried thread)
- **Picture**: the mark never moves; every world shows it from its first frame (the ink-wash breath is the one
  deliberate blank page). Every transition opens *from* the mark and is native to the incoming medium:
  CRT power-on, pixel blocks, curtain on the deco axis, glass shards, paper tear, knife wipe, print bands,
  page turn, ink bloom, the one line, an iris for light.
- **Sound**: one pulse (soft sub + felt tick on the beat) runs under every world; on top, each world plays one
  phrase on its own instrument over a single D-major progression; every cut has a sound made of the incoming
  medium (paper rip, CRT click, glass, ink drop, shutter).
- **Chrome**: one counter pill (NN/43 · style · event) carried across every cut.

## Structure
1. Open (0–3.5 s): dark keynote — the cue dot from STANDBY blinks, GO, the mark lights. "One call."
2. Act 1, craft (2 s each): hologram → ASCII → blueprint → art deco → stained glass → paper lantern → shadow puppet
   → papercut → woodcut → engraving → silent film.
3. Act 2, the rush (1 s each, hats on 16ths): spy titles → silkscreen → risograph → dossier → swiss → pictogram →
   game show → microgame → rubber hose → midcentury → sci-fi toon → cel anime → pixel RPG → HD-2D → low-poly →
   iso infographic → brick → pop-up → screencast → dataviz → whiteboard → crayon.
4. Breath (4 s): ink wash; the pulse stops; four brush strokes; "Any world you can imagine."
5. Act 3, paint and place (2 s each): watercolour → urban sketch → ukiyo-e → tilt-shift → impasto → backrooms → one line.
6. Reveal: the mark as a glass object → end card (dark keynote bookend).
