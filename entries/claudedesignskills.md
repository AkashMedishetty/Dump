## What it is

A collection of Claude Code skills, packaged as bundles (animation-components, authoring-motion, core-3d-animation, extended-3d-scroll, meta-skills) or as individual plugins. It covers:
- **2D and UI animation:** animejs, gsap-scrolltrigger, motion-framer, react-spring-physics, lottie-animations, rive-interactive, scroll-reveal libraries, barba-js, locomotive-scroll.
- **3D:** threejs-webgl, react-three-fiber, babylonjs, playcanvas, aframe-webxr, pixijs-2d.
- **Pipelines:** blender-web-pipeline, substance-3d-texturing, spline-interactive, web3d-integration-patterns.

## Ideas for us

- Install the `core-3d-animation` and `authoring-motion` bundles in installation repos so Claude writes idiomatic GSAP, Rive and R3F.
