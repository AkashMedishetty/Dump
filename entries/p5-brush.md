## What it is

Custom brushes (pens, markers, charcoal...), vector fields that bend strokes, watercolour-style fills with bleed, and hatching, all in WebGL mode.

## Ideas for us

- Painterly installation walls, and hand-drawn reels with a consistent "medium".

## Notes

Watercolour fills are slow without a dedicated GPU (per ClaudeAnimationBase). Metadata (exists, stars, license, last push) checked 2026-10-03; description from general knowledge, README not re-read.
