## What it is

Skeletons, meshes, IK constraints and animation blending for 2D characters. Runtimes exist for PixiJS, Phaser, Egret, Hilo and three.js. It can also import Spine JSON.

## Ideas for us

- Rigged 2D creatures for living-swarm without a Spine license.

## Notes

The DragonBones editor is no longer actively developed; the JS runtime still received updates in 2026. Metadata (exists, stars, license, last push) checked 2026-10-03; description from general knowledge, README not re-read.
